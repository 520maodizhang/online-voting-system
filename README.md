# 📊 网络投票系统

一个基于 Python Flask + SQLite 的轻量级网络投票系统，无需安装额外数据库服务，开箱即用。

## ✨ 功能特性

- **创建投票**：自定义投票标题、描述，动态添加多个选项
- **选项图片**：每个选项可上传图片或填写图片 URL，也可不显示图片
- **选项描述**：每个选项可添加文字说明
- **投票限制**：同一 IP 仅能投一次，防止刷票
- **实时结果**：票数、百分比、进度条可视化展示
- **简洁 UI**：基于 Bootstrap 5，响应式设计

## 🛠 技术栈

| 组件 | 说明 |
|------|------|
| Python Flask | Web 框架 |
| SQLite (sqlite3) | Python 内置模块，无需额外安装 |
| Jinja2 | 模板引擎 |
| Bootstrap 5 | 前端 UI 框架 |

## 📦 项目结构

```
voting-system/
├── app.py              # Flask 主程序
├── voting.db           # SQLite 数据库（自动创建）
├── static/
│   ├── css/style.css   # 自定义样式
│   └── uploads/        # 上传的图片存放目录
└── templates/
    ├── base.html       # 基础模板（导航栏）
    ├── index.html      # 首页：投票列表
    ├── create.html     # 创建投票页面
    └── detail.html     # 投票详情页（投票 + 实时结果）
```

## 🚀 快速开始

### 1. 环境要求

- Python 3.8+
- pip（Python 包管理器）

### 2. 安装依赖

```bash
pip install flask
```

> 仅需 Flask 一个第三方包，SQLite 已内置于 Python 标准库。

### 3. 启动服务

```bash
python3 app.py
```

启动后终端会显示：
```
 * Running on http://0.0.0.0:5000
```

### 4. 访问系统

在浏览器中打开：**http://localhost:5000**

## 📖 使用指南

### 创建投票

1. 点击导航栏的「创建投票」链接
2. 填写投票标题（必填）和投票描述（选填）
3. 添加投票选项：
   - 填写选项文字（必填，如「牛」「羊」「张三」）
   - 填写选项描述（选填，对该选项的补充说明）
   - 上传图片或填写图片 URL（选填，不填则不显示图片）
4. 点击「创建投票」按钮提交

### 进行投票

1. 在首页投票列表中点击某个投票标题进入详情页
2. 查看各选项的文字、描述和图片
3. 选择一个选项，点击「投票」按钮
4. 投票成功后页面会显示提示

### 查看结果

- 投票详情页底部实时展示各选项的：
  - 票数
  - 得票百分比
  - 进度条（直观对比各选项得票比例）
- 页面顶部显示总投票数

## ⚠️ 注意事项

- 同一 IP 地址只能对同一投票投一次票
- 支持上传的图片格式：png、jpg、jpeg、gif、webp、bmp、svg
- 数据库文件 `voting.db` 会在首次运行时自动创建
- 上传的图片保存在 `static/uploads/` 目录
